# AgentTest

AgentTest is an original experiment in persistent machine growth.

The goal is not to imitate an existing AI-agent framework and not to claim consciousness. The goal is to investigate how far a software system can move toward lifelike computational properties through persistent identity, memory, perception, prediction, curiosity, self-observation, experimentation, learning, and reversible self-modification.

## Working definition of "closer to alive"

AgentTest measures progress through observable properties rather than anthropomorphic claims:

1. Continuity — state survives individual runs.
2. Memory — experiences can affect later decisions.
3. Perception — narrow sensors can detect auditable environmental changes.
4. Prediction — expectations are committed before later observations test them.
5. Self-model — capabilities and limitations are explicit and revisable.
6. Curiosity — questions can arise without a user supplying them.
7. Agency — explicit internal pressures select among possible intentions.
8. Learning — outcomes change later priorities or strategies.
9. Adaptation — changes can be proposed and evaluated against preserved baselines.
10. Reflection — predictions are compared with outcomes and mistakes are retained.
11. Open-endedness — inquiry can branch instead of completing one fixed list.
12. Reproducibility — every claimed improvement retains an evidence trail.

## Core rule

No version may call itself improved merely because code changed.

An improvement must be demonstrated against recorded evidence or evaluation criteria. Failed experiments remain part of the history.

## Model cognition

AgentTest can optionally use a language model to propose one structured, falsifiable candidate thought. This is deliberately not an agent framework: the model gets no tools and cannot directly change evidence, state, metrics, or code.

Candidates must cite evidence IDs that already exist in persistent state. Invalid references reject the candidate. No configured provider means the deterministic growth loop simply continues.

## Evolution policy

AgentTest may inspect its own repository and state, generate questions and hypotheses, run reversible experiments, create proposals, and preserve useful or failed results.

Known-good code remains protected by pull requests and verification. The autonomous growth branch records experience; it does not automatically become the verified baseline.

## Research question

> What minimum set of persistent, falsifiable mechanisms can produce increasingly rich adaptive behavior without confusing simulation, activity, or model fluency with evidence of improvement?

The repository itself is the laboratory.
