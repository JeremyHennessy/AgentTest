# Design: Genesis Phases 0–1

## Why this is not an agent-framework clone

AgentTest intentionally has no imported agent graph, no synthetic team of role-playing agents, and no planner/executor architecture copied from an existing autonomous-agent project.

The design begins with a narrower question:

> What observable properties would have to accumulate before a persistent computational process becomes more organism-like over time?

The answer is represented as a **vector of evidence**, not a single "alive score."

## Current loop

```
auditable environment sensor ─┐
                             ├→ persistent episode
human/external stimulus ─────┘          ↓
                                  accumulated memory
                                         ↓
                               detected environmental change
                                         ↓
                                internally generated question
                                         ↓
                              selected falsifiable experiment
                                         ↓
                                   outcome evidence
                                         ↓
                                      reflection
                                         ↓
                               revised future priorities
```

An outcome is never invented by the loop. External evidence must be recorded explicitly.

## Phase 1 perception

The first sensor deliberately observes only the checked-out repository:

- current branch;
- tracked-file count;
- Python-file count;
- Python source-line count;
- test-file count;
- clean/dirty working-tree state.

Commit SHA and observation time are recorded for provenance but excluded from surprise detection because they change routinely and would create artificial novelty.

A difference in measured fields becomes a **surprise**, not a conclusion. The system responds by asking what caused the change and whether a verified capability actually changed.

## State versus history

`state/organism.json` is the current working state.

`state/journal.jsonl` is append-only history generated by cycles. State may evolve; history is evidence.

Schema migrations are additive and must preserve earlier episodes and experiments.

## Why no automatic self-merge

A process that can rewrite the criteria used to judge itself can trivially declare success. Autonomous exploration therefore occurs on a separate branch, while changes to the verified baseline remain inspectable.

## Current missing capabilities

- generative model cognition;
- broad external perception;
- long-horizon world models;
- semantic memory retrieval;
- environmental actions beyond repository-state recording;
- autonomous code synthesis;
- causal experiment execution;
- social models;
- temporal/homeostatic drives;
- any defensible evidence of subjective experience.

Those are research targets, not features to pretend already exist.
