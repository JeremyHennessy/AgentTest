## New developmental hypothesis (not an independent holdout)

Repeated unfamiliar-family selection is a preventable information-use
bottleneck. Version 2 prospectively changes the action-selection objective to
permit testing an *already observed action family in a previously untested
context*. It never installs a known route, goal, desired outcome or
experimenter-chosen response, and it still includes repeated failures.

At [37867768760](https://github.com/JeremyHennessy/AgentTest/actions/runs/37867768760),
the version 2 follow-up passed 20 dedicated tests and completed the same
four-layout, 12-action exploratory window:

| Layout | Previously observed family used | Local evidence used | Prequential Brier | Uniform Brier |
|---|---:|---:|---:|---:|
| 1 | 3 | 0 | 0.84092563 | 0.85714286 |
| 2 | 5 | 0 | 0.83203441 | 0.85714286 |
| 3 | 6 | 0 | 0.78169866 | 0.85714286 |
| 4 | 3 | 0 | 0.88359788 | 0.85714286 |

**Interpretation:** 17/48 predictions now use empirical family evidence,
and three layout averages beat the weak uniform control while one performs
worse. This is a positive mechanism check and mixed predictive outcome, **not
proof of adaptive intelligence or statistically generalizable improvement**.
The same mirrored development layouts and the earlier negative pilot informed
version 2's design. Do not relabel the follow-up as preregistered held-out
science.

## Independent comparator and custody improvement

Subsequent source changes add an additional **pooled-global-history
predictor** that receives the same earlier outcome categories but ignores
action-family and context identity. It is scored prequentially on the *same
actually executed outcomes*, without affecting the candidate's actions.
The runner is now included in source hashes alongside the policy, world and
public-menu module: future changes require a new capsule.

The comparator is still a simple baseline; winning against it would not
establish useful goal attainment, retention under environmental reversal, or
cross-world transfer. Preserve failures, all actions, nulls, decision-time
forecasts, denominators and exact source revision.

   bridge that preserves a genuine selected question/goal through action,
