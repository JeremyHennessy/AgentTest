Status: source proposal for independent review. No trials, runtime tests,
publication, merge or live activation authorized by this preparation.

An already chosen explore_empirical_frontier intention may return the text of
the minimum currently obtainable passive question. Admission is common to both
arms and occurs after drives/intention are chosen, before generation. The normal
agenda remains the final selector. Its existing legacy focus coefficient is
transferred by choosing a different generated question: this is an explicit
policy intervention, not neutral evidence plumbing or a score improvement.

The draft pool covers every provable copied passive contract across registered
sources and feature/relation families, including a matching active owned
experiment if present, without requiring one. A qualifying question must have
the bridge's validated raw-source/episode contract, current visibility, and an
additional record committed in its finite acquisition manifest plus an opaque
receipt from the driver validating the next scheduled envelope's existence,
outer hash, raw commitment, exact position and chain before generation. The predicate
does not read a future payload, prefer a world/name/relation, rank objective
scores, or infer measurement access from proposed/schema status. Declared
capacity is supported by the study's frozen three-file input schedule; live
passive access alone cannot promise a temporal successor. Missing next feature
would be nonevaluable evidence, never a refutation or resolution credit.

last_selected_cycle, created_cycle, question ID, including its existing zero/
None normalization. No qualifying contract retains the generic frontier text.
With the policy enabled, generic frontier source_evidence_refs annotations apply
only to the exact generic template without a different source tag; a passive
candidate keeps its own source/episode refs. Off mode preserves the original
unconditional annotation, including source-tagged template collisions.
Intention origin is separate in the opt-in result/journal trace.

counterfactuals. CLI/Core changes do not add any external observation/action
executor, provider, API credential or manual candidate/selection input.
