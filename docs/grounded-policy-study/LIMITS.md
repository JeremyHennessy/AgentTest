# Limits and activation boundaries

This foundation establishes a software integration result on one authored case.
It establishes no predictive benefit, action usefulness, learning, generalization,
representation evolution, broader corpus coverage or new-world readiness.
The 32-pair scientific comparison has never run.

## Known scientific limitation

The frozen scientific scorer has a known incomplete-run ordering-classification defect: a second owned outcome can exist without a committed common F set and be classified incomplete instead of invalid. The scientific scorer and driver are unadmitted. Correction and verification belong to the separate scientific extension; the completed software fixture performed no scientific scoring and remains valid.

The foundation must not be treated as an approved scientific scorer or driver.
Its original source is preserved for provenance; this annotation is not a fix.

## Activation

The frozen native-fixture controller and worker retain
`REAL_FIXTURE_ADMISSION_REVIEWED = True`, exactly as executed. Their scientific
guards remain False. The real-fixture setting is historical approval for one
exact profile and source closure, not a reusable execution permission. The
original profile fixes the identity, source/runtime hashes, output root and
one-attempt marker location; that original attempt has already been consumed.

No operational GO receipt or reviewed native binary is included. The historical
profile under `evidence/` retains its original absolute paths; it is an archival
review artifact, not a portable launch configuration. Do not regenerate a GO
receipt, alter the profile, clear or relocate its marker, select another output
root, or compile an enabled fixture merely to reproduce this publication.

The supported publication entry point is the authored-data test runner.
Default unittest discovery finds its narrow wrapper. The real fixture is never
registered as a test, and no CI workflow or scientific dispatch is added.
The native launcher used by those tests is compiled in the authored-stub role.
The wrapper provides neither real API sources nor real fixture admission inputs.

## Resource claims

The native Linux design uses one allowed CPU and a fixed 850-second internal
window, below the unchanged 900-second CPU and 1,500-second wall ceilings under
ordinary trusted Linux scheduling and kernel semantics. This is not a hardware
real-time guarantee or a promise about a failed kernel. Soft address-space
budgets are 32 MiB outer + 96 MiB controller + 384 MiB sole sequential child.
Supervisor hard limits preserve child inheritance; the audited code does not
raise its own soft bound. Reporter and reconciliation roles share the child slot.

Authored tests exercise limit refusal, expiry, source mismatch, parent death,
bounded pipes and failure finalization. One real software fixture exercised the
capped API transport. These facts do not establish full scientific resource,
output-inventory or native-bootstrap readiness. Raw terminal fields which remain
False are preserved. Observed fixture times are pre-exit measurements.

The prospective scientific artifact allocation is 192 MiB, including a 1 MiB
finalization reserve. The completed fixture used its separate 25 MiB inventory.
Accounting for one does not prove successful execution of the other.

## Portability and evidence access

The numerical source paths, interpreter hash and Decimal runtime are intentionally
pinned. A new runtime needs prospective review; publication never silently swaps
fingerprints. Zero-world tests may pass on another supported Linux environment
without making that environment an approved scientific runtime.

Raw fixture files and the reviewed native binary were verified locally, with
exact hashes in the publication inventory, before the workspace became unavailable
during session recovery. They are currently unavailable, are not committed here,
and do not have a download link. See [RECOVERY.md](RECOVERY.md). A repository-only reviewer can inspect
source, protocol, included receipts and authored-test results, but cannot repeat
the complete 794-row saved-evidence audit without obtaining those omitted exact
artifacts. Source publication and raw-evidence access are distinct review gates.
