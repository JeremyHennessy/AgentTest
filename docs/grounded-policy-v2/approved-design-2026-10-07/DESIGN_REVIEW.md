## Why this is a coherent next step

### Grounded formation without overstating invention

D supplies observed movement displacements and the values used in a small conditional language. It must contain both zero and one nonzero displacement for a movement to obtain a cohort. Missing diversity, model-class mismatch and generator overflow remain explicit coverage failures, not invitations to insert the simulator's orientation table or a desired route.

The finite language contains two observed-displacement constants and one-condition rules over position, inventory identities or visible identities. Fixed feature order and chronological first value occurrence avoid source/ID spelling as a top-five rule tie breaker. Full public feature context remains the exact evidence-matching key. N is disclosed as an authored unresolved-process model. None of these steps is representation growth or adaptive hypothesis-set extension.

Each action-bearing case has at least two currently available concrete rules predicting different public positions. Concrete case hypotheses remain immutable. A later case is separately grounded and identified, not a silently migrated v1 inquiry or a fabricated resumption. The design honestly narrows the first claim to movement/position rather than asserting all investigation goals must be covered.

### Selection authority and outcome use

The new backend is internal, creation-time pinned, and run once within T1. The caller cannot submit a winner, receipt, score, command callback or per-decision backend. The complete at-most-four-action menu and forecast records are frozen before actuation. A pure independent receipt checker reconstructs derivations, eligibility, evidence, exact weights, forecasts, scores and the expected threshold/tie-aware result, but does not run another backend selection or issue a substitute capability.

The proposal preserves the substantive T1/T2/T3 obligations from #222: selected ownership, source and derivation validation, freshness, CAS, one-use authority, durable full outcome, atomic copied-world consumption, interpretation once, and no replay or changed-rule credit. These are requirements to implement and test, not inherited guarantees merely because v1 passed tests.

The first-stage policy choice, action and T3 must match between both arms. At stage two, the only intervention is whether the updater can consume the actual first owned transition. The retained event is eligible only when its pre-context equals the current context and its action matches the forecast. The subsequent forecast and selection therefore have an explicit reproducible dependency on the retained outcome. Null first selections and context-changing first actions remain zero-effect possibilities. No harness return, runner-up, relabelled legacy experiment or forced resumption closes the loop artificially.

The mixture forecast is a separate reviewed v2 record. It does not reinterpret #222's static per-hypothesis predictions or its case-local belief version as an adaptive model. Missing and invalid concrete predictions are removed before context-local priors and updates; N alone cannot create an inquiry or forecastable case.

### Compatibility is now correctly bounded

The actual v1 source manifest pins every production Python file and every Python file under its executive package. Adding a backend file there is already a source change for old capsules. The proposal now requires unchanged frozen-source v1 execution plus a separately versioned and completely pinned v2 package/checkout. It forbids v1 monkeypatching, source-acceptlist expansion and automatic migration.

A future legacy adapter is optional; the minimal next implementation does not need to manufacture one. If added later, it must retain actual legacy selection/routing proof, incomplete candidate-summary disclosure and B's truthful generic-experiment deferral. Preserving the old control does not require making the old selector the new policy's architecture.

### Falsifiable, bounded comparison

Both arms share generated models, D/U, current context, algorithm, first-stage choices/outcomes, statuses and budgets. Masks operate at the second policy intake while full actual history remains in the authority/audit boundary. The design explicitly acknowledges that current context and deterministic common inputs can reveal information indirectly; it claims removal of the explicit event/update channel, not total ignorance.

An independent evaluator produces common four-movement outcomes only after second-stage T1. Those probes are counted, never supplied to policy, and cannot select later anchors. Brier loss is scored for every model-supported movement in the common pre-outcome set, not merely the action an arm chose. Probability shifts, entropy, rule counts and changed choices cannot substitute for lower predictive loss.

The protocol declares 32 fixed paired anchors from four mirrored layouts; mirrors and repeated contexts are not independent trials. Context-balanced and raw/per-layout results are required. Forecast-empty and null cases have explicit rows, not zero losses. Coverage, regression guard, predictive threshold and behavioral adequacy are predeclared, with ordered invalid/incomplete/adverse/inconclusive/no-benefit/predictive-only/full-predicate results. A changed or discriminating action is expressly not comparative realized action benefit.

The proposed global ceilings are coherent: 256 neutral setup transitions, at most 128 owned transitions, 128 independent probes, at most 512 new transitions total, and exactly 128 scheduled policy decisions including nulls. Each arm is a fresh explicitly created two-decision branch, not a copied sealed capsule with reset counters. Neutral exploration counters update exactly once on the pre-action signature/command for every actual attempt, including blocked attempts; branches never alter the neutral schedule. The study has additional byte, memory, CPU and wall-time ceilings. A single independent controller now measures the full process tree from startup/source validation through final reporting/sealing, with a reserved failure-report envelope, reconciled durable counts and explicit unknown/invalid accounting if evidence is lost. All actual simulator invocations, including crash recomputations, consume the global 512-call ceiling; durable actions and invocations remain separate reported counts. No scientific replay or favorable extension is implicit.

## Conditions that must stay visible during implementation

1. **Keep the fork narrow.** A new v2 schema and closure are necessary. Do not modify the v1 package/control, production selection, old phase metrics or historical study results to accommodate it.
2. **Test actual materialized policy views.** The withheld first event must not reappear through recorder counts, earlier frames, beliefs, previous decisions, cached weights, file paths, provenance hashes interpreted as features, or a permissive authority object. Verify both semantic matching and complete per-run ownership independently.
3. **Test duplicate and label invariance.** Duplicate source events must not change D construction, retained rules, posterior mass or selection. Changed-body duplicate and unauthorized source substitution must reject. Consistent opaque-ID alpha-renaming must preserve semantic outputs without weakening actual source authorization.
4. **Test arithmetic and authority negatives.** Implement exact rational bounds, deterministic entropy serialization, threshold/tie behavior, unavailable-model normalization, complete menu checks and rejection-before-mutation for forged/stale/foreign receipts. Policy-only fixtures should include absent cohorts, changed contexts, contradictions, alternating/noisy outcomes and all-model misspecification.
5. **Prove new storage and global accounting.** V1's serialized reserve does not certify v2's models, masks and forecasts. Verify exact byte bounds, reserved T2/T3 completion, crash/restart behavior and nonresettable whole-study counters before executing the study. An enclosing supervisor must account for startup/source validation, neutral setup, both owned action stages, scorer probes, every restart and validation, reporting, locking, sealing and finalization. Use cumulative whole-run process-tree CPU, uninterrupted wall time and explicitly defined global memory/output measurements, not per-phase snapshots. Startup and finalization failures must reach structured invalid/incomplete reporting even if a worker never emits a result. Freeze and adversarially test the accounting and failure paths before any stream is generated.
6. **Keep interpretation claims narrow.** Exact-context retention may amount to predicting another blocked move in a deterministic world. The two-stage study does not test forgetting, sustained retention, transfer, cross-context belief updates, hypothesis evolution, noise robustness in a stochastic environment, or efficient long-term exploration.
7. **Freeze before generating any scientific stream.** Scorer source, masks, proposal/source manifests, initial input construction, numerical conventions, resource enforcement and reporting rules need an independent pre-execution lock. If coverage is poor, the specified null/inconclusive result is terminal; do not tune or replenish.
