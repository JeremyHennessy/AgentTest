## Recommendation

Retain the tested transaction boundary and replace its temporary selection
backend through an explicit reviewed API change. Then run **one small prospective
synthetic comparison of a retained owned-action outcome versus that outcome withheld**
inside the same new policy. Both arms make an identical internally selected first
action, persist and interpret its result, then make a matched second decision.
Ask whether retaining that result improves prediction and changes the next test.

Do not compare a bundle of new mechanisms against legacy Core and attribute a
win to “curiosity.” Both scientific arms use the same generated hypothesis set,
inquiry admission, algorithm, current observation, lifecycle and action budget.
Only the first owned transition available at the second policy intake differs. The experiment
does not test the benefit of the generator itself, representation growth,
autonomous long trajectories, or multi-owner resumption.

The smallest useful target is **public position after one movement action**.
It is always observable in the existing Challenge sensor, unlike the entity
feature that A's move can occlude. Position is a declared initial research scope,
not an environmental reward or a prescribed destination. All four movement
directions remain possible; no route, gate-opening goal, target answer, successful
receipt quota, or forced resumption is supplied.
