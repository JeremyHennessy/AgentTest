## Mechanism and boundaries

The inlet is absent/off by default and excludes the default production store path.
It accepts one bounded descriptor/acquisition-manifest/raw-record bundle. JSON
duplicate keys/unknown fields/nonfinite/bool numbers reject. Coordinates remain
[-2,2]; inventory order and raw bytes are retained. Geometry, identity, timestamp
syntax/acquisition interval, genesis payload, ordered raw hashes and chain are
checked. An accepted sequence's exact raw replay is idempotent; changed content,
unseen noncontiguous sequence and non-increasing world cycles reject before save.
The first descriptor is trusted because its exact bundle was reviewed/frozen;
integrity checks are not external source authentication.

Only position.x/y, inventory.count and publicly visible anonymous entity state
are interpreted. Missing/occluded values are unknown, never forward-filled or
compared across a missing middle record. Every evaluable feature emits both
equality/change alternatives; complements share a feature-pair identity. A maximum
three-record source bounds current candidates to 38 and retained versions to 76.
Descriptive uncertainty uses the unchanged research temporal entropy formula and
never affects priority, drive, tie-break or intention strength.

The pure compiler rederives public pairs and checks the exact normalized episodes,
counts, relation, descriptor and evidence refs. Feature identity is namespaced by
descriptor+feature hash; readable mapping remains in the trace. Its prospective
test specification requires a subsequent adjacent evaluable pair, not grounding
evidence; missingness is no outcome. It does not create an experiment, intention,
authority or resolution result.

Stable-family questions register in the ordinary admission stage after legacy
question generation. One source-bound registry predicate is revalidated every
cycle, including retained threads. Source exhaustion removes eligibility.
Provenance refs are not fabricated thread-progress refs. Existing active-experiment
semantics, scoring, drive computation, legacy question, agenda capacity, tie-break
and Planning Lab remain unchanged. `propose_native_inquiry` is never called.
Only the actual normal decision object can reach the guarded post-selection
allocation hook; generic intention/target/label/flag paths cannot allocate it.
The hook was not positively exercised because no native question was selected.
This is a single-writer copy experiment, not live authorization/storage fencing.
