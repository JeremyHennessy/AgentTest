How live status is read

Heartbeat status is read from autonomous/growth/state/heartbeat_operation.json. A receipt older than five minutes is marked aging, not declared stopped. Missing or invalid values remain unavailable.

For the optional map, the growth branch is resolved once to an immutable commit. That exact commit’s organism file supplies the map, plan and cycle. A newer heartbeat never relabels the older snapshot as current. Repository errors retain the last visible value with an explicit warning.

Polling pauses while this tab is hidden. Public GitHub API checks are limited to every five minutes; the small heartbeat file refreshes every minute. No credentials, model services or write requests are used.
